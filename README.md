# FAMAX

Projeto configurado para rodar em ambiente Node.js com TypeScript usando Vite.

## Requisitos

- Node.js 20+
- npm

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

O Vite sobe um servidor local e compila os arquivos TypeScript referenciados nos HTMLs.

## Build de produção

```bash
npm run build
```

Os arquivos otimizados são gerados em `dist/`.

## Preview do build

```bash
npm run preview
```
